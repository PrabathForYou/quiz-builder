# Quiz Builder

Quiz Builder is a REST API for storing multiple-choice questions and generating quizzes from a random selection of questions in a chosen category. It is built with Spring Boot, Spring Data JPA, and PostgreSQL.

## Features

- Add and list multiple-choice questions
- Look up a question by ID
- Filter questions by category
- Create a quiz from randomly selected questions in a category
- Retrieve quiz questions without exposing their correct answers
- Automatically create and update the database schema through Hibernate

## Tech stack

- Java 17
- Spring Boot 4.0.6
- Spring Web MVC
- Spring Data JPA / Hibernate
- PostgreSQL
- Maven
- Lombok
- Docker

## Requirements

For local development, install:

- Java 17 or newer
- PostgreSQL

The repository includes Maven Wrapper scripts, so a separate Maven installation is not required.

## Configuration

The default configuration is in `src/main/resources/application.properties`:

```properties
server.port=9090
spring.datasource.url=jdbc:postgresql://localhost:5432/quiz-builder
spring.datasource.username=admin
spring.datasource.password=me@123
spring.jpa.hibernate.ddl-auto=update
```

Create the database and user to match these settings, or override them with environment variables:

```bash
export SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5432/quiz-builder
export SPRING_DATASOURCE_USERNAME=admin
export SPRING_DATASOURCE_PASSWORD='your-password'
export SERVER_PORT=9090
```

For shared or production environments, provide credentials through environment variables rather than committing them to configuration files.

## Run locally

On Linux or macOS:

```bash
./mvnw spring-boot:run
```

On Windows:

```powershell
./mvnw.cmd spring-boot:run
```

The API is available at `http://localhost:9090` by default.

To build and run the packaged application:

```bash
./mvnw clean package
java -jar target/quiz-builder-0.0.1-SNAPSHOT.jar
```

## API reference

### Questions

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/question` | Return all questions |
| `GET` | `/question/{id}` | Return a question by ID |
| `GET` | `/question/category/{category}` | Return questions in a category |
| `POST` | `/question` | Add a question |

Add a question:

```bash
curl -X POST http://localhost:9090/question \
  -H 'Content-Type: application/json' \
  -d '{
    "questionTitle": "Which keyword creates a subclass in Java?",
    "option1": "implements",
    "option2": "extends",
    "option3": "inherits",
    "option4": "super",
    "rightAnswer": "extends",
    "difficultyLevel": "Easy",
    "category": "Java"
  }'
```

List questions in a category:

```bash
curl http://localhost:9090/question/category/Java
```

Question objects have the following fields:

| Field | Type | Notes |
| --- | --- | --- |
| `id` | integer | Generated by the database; omit when creating a question |
| `questionTitle` | string | Question text |
| `option1` ... `option4` | string | Available answers |
| `rightAnswer` | string | Correct answer |
| `difficultyLevel` | string | Difficulty label |
| `category` | string | Used to filter questions and build quizzes |

### Quizzes

| Method | Endpoint | Description |
| --- | --- | --- |
| `POST` | `/quiz/create?category={category}&numberOfQuestions={count}&title={title}` | Create and persist a quiz |
| `GET` | `/quiz/{id}` | Return the questions for a quiz |

Create a five-question Java quiz:

```bash
curl -X POST 'http://localhost:9090/quiz/create?category=Java&numberOfQuestions=5&title=Java%20Basics'
```

Retrieve it (replace `1` with the generated quiz ID):

```bash
curl http://localhost:9090/quiz/1
```

Quiz retrieval uses a reduced question representation that deliberately excludes `rightAnswer`. Quiz creation currently returns a confirmation message, not the new quiz ID. If fewer matching questions exist than requested, the quiz is created with the available matches.

Category matching is exact and depends on the values stored in PostgreSQL.

## Docker

Build the image:

```bash
docker build -t quiz-builder .
```

If PostgreSQL is running on the Docker host, run the application with a datasource URL reachable from the container:

```bash
docker run --rm -p 9090:9090 \
  -e SPRING_DATASOURCE_URL=jdbc:postgresql://host.docker.internal:5432/quiz-builder \
  -e SPRING_DATASOURCE_USERNAME=admin \
  -e SPRING_DATASOURCE_PASSWORD='your-password' \
  quiz-builder
```

On Linux, you may also need `--add-host=host.docker.internal:host-gateway`. Alternatively, connect the application and a PostgreSQL container to the same Docker network and use the database container name as the hostname.

The image accepts `SERVER_PORT` and `SPRING_PROFILES_ACTIVE`; remember to update the published port when overriding `SERVER_PORT`.

## Tests

## Current scope

The API currently does not provide authentication, question or quiz update/deletion, answer submission, scoring, validation, or generated API documentation.
